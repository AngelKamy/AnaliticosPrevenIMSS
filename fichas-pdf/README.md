# Publicar fichas técnicas mensuales

1. Guarda el PDF en esta carpeta. Usa un nombre como `2026-10-prevencion.pdf`.
2. Agrega una entrada a la lista de `../js/fichas-indice.js`, con el mes como número de 1 a 12 y el nombre de archivo exacto.

```js
{ anio: 2026, mes: 10, titulo: 'Título de la ficha', archivo: '2026-10-prevencion.pdf' }
```

3. Abre Fichas en el sitio estático, selecciona el año y el mes y verifica ambos enlaces, **Abrir PDF** y **Descargar PDF**.

Puedes añadir varias entradas para el mismo mes. **Todos los meses** muestra las fichas publicadas, de la más reciente a la más antigua. Si eliges un mes sin ficha, verás un aviso. La publicación inicial contiene las fichas de Coberturas de enero a septiembre de 2026.
